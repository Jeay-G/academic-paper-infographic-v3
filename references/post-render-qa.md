# Step 3 — 成图一致性与发布质量 QA

这一步发生在最终图片生成之后。

不要重新做一次论文分析。

比较：

**最终图片 vs 已锁定 final_content_pack**

检查以下内容。

## 1. 关键事实与数字

- 数字是否被改写、错写、漏写。
- 单位、组别、方向是否正确。
- 是否出现 ImageGen 生成的虚构文字或数字。

任一关键数字错误 → 必须修正。

## 2. MUST_SHOW 覆盖率

逐项检查所有 MUST_SHOW：

- 是否真正出现在图中。
- 是否被缩成一句抽象标签。
- 是否被装饰性插画掩盖。

缺失关键 MUST_SHOW → 不可交付。

## 3. 解释完整性

对每个核心结论问：

**读者能不能从图中看懂它为什么成立？**

尤其检查：

- 机制链是否断裂
- 事件链是否断裂
- 场景链是否只剩场景名称
- 系统流程是否只剩组件名
- 主结果是否失去关键对照/消融支撑

如果只剩“作者说了什么”，看不出“为什么这么说”，则判定不合格。

## 4. 科学强度

检查图片有没有在视觉上把：

- 相关画成因果
- 可能画成确定
- design fiction 画成现实结果
- 作者讨论画成实验结论

有则修正。

## 5. 中文与可读性

检查：

- 中文错字
- 乱码
- 标题错误
- 文本被截断
- 字号过小
- 异常换行
- 数字不可读

## 6. 视觉质量

最终图应：

- 一眼知道论文研究什么
- 顺着图能理解核心论证
- 重点没有被埋没
- 信息丰富但不混乱
- 不像 PPT / Canva / 网页截图
- 达到可发布、可分享水平

最终只需判：

- A｜可直接用
- B｜内容正确但需要视觉/文字局部修正
- C｜关键内容错误、缺失、解释链断裂或视觉明显不可用
