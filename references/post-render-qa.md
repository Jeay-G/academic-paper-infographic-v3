# Step 3 — 成图一致性与发布质量 QA

这一步发生在最终图片生成之后。

不要重新做一次论文分析。

比较：

**最终图片 vs 已锁定 final_content_pack**

检查以下内容。

## 1. 关键事实与数字

- 数字是否被改写、错写、漏写。
- 单位、组别、方向是否正确。
- 是否出现 ImageGen 生成的虚构文字或数字。

任一关键数字错误 → 必须修正。

## 2. MUST_SHOW 覆盖率

逐项检查所有 MUST_SHOW：

- 是否真正出现在图中。
- 是否被缩成一句抽象标签。
- 是否被装饰性插画掩盖。

缺失关键 MUST_SHOW → 不可交付。

## 3. 解释完整性

对每个核心结论问：

**读者能不能从图中看懂它为什么成立？**

尤其检查：

- 机制链是否断裂
- 事件链是否断裂
- 场景链是否只剩场景名称
- 系统流程是否只剩组件名
- 主结果是否失去关键对照/消融支撑

如果只剩“作者说了什么”，看不出“为什么这么说”，则判定不合格。

## 4. 科学强度

检查图片有没有在视觉上把：

- 相关画成因果
- 可能画成确定
- design fiction 画成现实结果
- 作者讨论画成实验结论

有则修正。

## 5. 中文、对比度与可读性

检查：

- 正文在 PNG 的 100% 原始尺寸下能直接辨读，不要求用户放大。
- 每种正文、标题、注释、标签和数字的文字色，都与它实际所在背景具有足够对比度；尤其检查深色章节和浅色内嵌框的反转配色。
- 正文是否被继承的深色文字色留在深色背景上，或被低对比度灰色弱化。
- 正文建议至少 18 CSS px，注释／图表标签至少 14 CSS px；如因内容过密而更小，必须重排或扩高画布。
- 每种文字／背景组合的计算对比度：普通文字至少 4.5:1，大字号粗体至少 3:1。任一组合不达标必须修复。
- 在 50% 与缩略图下，主标题、主视觉关系和关键数字仍清晰可辨。


## 6. 视觉质量

### 视觉完成度 Gate

内容正确不代表视觉通过。出现以下任一情况，不能判 A，必须先修正：

- 没有论文专属视觉身份；替换标题与正文后仍可把同一套版式用于另一篇论文。
- 从头到尾只有一种视觉节奏，或主要依靠矩形、横线、文字和普通柱状图。
- 颜色和图形只是装饰，没有对应研究对象、状态、组别或证据。
- 图像路线中，装饰性插画多于解释性插画，或出现与论文无关的漂亮场景。
- HTML 路线中，缺少足够强的论文专属 SVG 主视觉，或用通用图标和普通流程框顶替。
- 依赖通用默认配色/皮肤；画面很满却没有焦点，或干净但像自动排版、缺少设计完成度。
- 看起来“没有错误”，却不具备可公开展示的视觉完成度。

A 级必须同时满足：内容正确、论证完整、可读、拥有论文专属视觉语言、有明显设计完成度，并能让读者不经解释就感到这张图经过针对性设计。

通过视觉 Gate 的图还应：一眼说明研究对象、顺着图看懂核心论证、重点清楚、信息丰富而不混乱，适合发布和分享。

最终只需判：

- A｜可直接用
- B｜内容正确但需要视觉/文字局部修正
- C｜关键内容错误、缺失、解释链断裂或视觉明显不可用
