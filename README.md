# Academic Paper Infographic Skill V3

## Core workflow

1. Read the source completely.
2. Build and verify the final on-image content pack in one pass.
3. Lock MUST_SHOW content before any rendering.
4. User selects renderer: Image or HTML.
5. Default output is a vertical long infographic; do not ask for a size unless the user explicitly imposes one.
6. Render without re-summarizing.
7. Post-render QA compares the image against the locked content pack.

## Key design principle

Compress wording, not reasoning.

The graphic must let the reader understand not only what the paper concludes, but why the conclusion is supported.
